| 区间 | 解读 |

## 五、慢变从哪来

### 5.1 直接查 DAC（100 秒低通后）

| 相关 | 值 | 含义 |
|---|---|---|
| **corr(DAC, ppsm)** | **0.677** | DAC 动 → 频率动 |
| **corr(DAC, frq)** | **0.902** | DAC 动 → X[1] 动 |
| **corr(ppsm, frq)** | **0.799** | 测量与估计一致 |

### 5.2 量级验证

```
DAC 低通 std      = 6.05 码
按 0.47852 ppb/码  ->  预测 ppsm std = 2895 ps
ppsm 低通 std     = 2122 ps

预测 2895 vs 实测 2122，同量级，差 27%
-> DAC 动作能解释慢变的主体
```

### 5.3 一个方法学教训

第一版分析算的是 corr(dDAC, dppsm)，得到 0.003，几乎为零。

```
原因:
  dDAC 只在 68/1577 秒里非零（96% 时间 DAC 不动）
  dppsm 每秒都在变（std 12 ppb）
-> 分母被每秒噪声撑大，信号被稀释
-> 必须【先低通再算相关】
```

**→ 这是本次分析中最重要的方法修正。**

## 六、更深一层：DAC 为什么动

### 6.1 数字

```
DAC 稳态段（t>=600）:
  std 6.24 码   范围 1873~1890
  6.24 码 x 0.47852 = 3.0 ppb 的频率调节
  而 X[1] 的 std 只有 1.015 ppb
-> DAC 动的幅度比它要纠正的偏差还大 -> 过冲/振荡
```

### 6.2 交叉相关：谁是主因

| lag | corr(DAC, ppsm) | corr(DAC, frq) | **corr(DAC, phs)** |
|---|---|---|---|
| 0 | 0.193 | 0.872 | **-0.819** |
| 1 | 0.194 | 0.876 | -0.814 |
| 10 | 0.205 | 0.907 | -0.773 |
| 50 | 0.236 | 0.941 | -0.541 |

**→ corr(DAC, phs) = -0.819（lag=0）**

```
DAC 与【相位】强负相关
-> 相位反馈项 K_PHASE x X[0] 在主导 DAC 的动作
-> 假设: K_PHASE = 0.005 可能偏大 -> 相位-频率耦合 -> 振荡
```

### 6.3 但这只是假设

```
不能用现有数据验证
因为改了 K_PHASE，DAC 轨迹就完全不同
-> 必须重新上板测
```

## 七、能写 / 不能写

### 可以写

```
1. 在相同 DAC（1886）、同一文件、同一时间段内，
   闭环的 OADEV 在 tau=50~100 秒比冻结工况高 4.6~6.4 倍；
2. 冻结工况的 OADEV 单调下降到 tau=200 的 0.239 ppb；
3. 闭环段 ppsm 每 100 秒段间范围 28.2 ppb，冻结段仅 0.99 ppb，差 28.6 倍；
4. 低通后 corr(DAC, frq)=0.902、corr(DAC, ppsm)=0.677，
   DAC 预测幅度（2895 ps）与实测（2122 ps）同量级；
5. 结构检查全部通过：边界码值连续、冻结段 DAC 恒定、
   PPS 序号连续、有效零值保留。
```

### 必须注明

```
1. 单次对照，温度/GNSS 仍有微小变化，不能唯一归因；
2. 冻结 DAC 未激励 EFC，不能排除 EFC 迟滞/动态；
3. tau=200 只有 2 个普通差分项，该点仅供参考；
4. 重叠 Allan 的重叠项不独立；
5. 「结构通过」不等于「因果证明」；
6. 所有指标相对本机 GNSS PPS，非绝对频率校准；
7. corr(DAC,phs)=-0.82 指向相位反馈，但这是相关性，不是因果证明。
```

### 不能写

```
- 闭环慢变的唯一原因是 K_PHASE 太大（只是相关，未做改参实验）
- 冻结工况证明了 OCXO 的真实稳定度（仍含 GNSS/测量链误差）
- 闭环比冻结差 8.4 倍（tau=200 的 2 个差分项不足以支撑）
- 已找到解决方案（只找到方向）
```
