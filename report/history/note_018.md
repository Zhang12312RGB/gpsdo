## 七、能写 / 不能写

### 可以写

```
1. A/B 只改了 EXP_PHASE_TERM_EN 一个变量；
2. 两段门控零坏样本（3525 / 3970 秒）；
3. t=600~3524：B 的 X[1] std 0.1963 vs A 0.2645；
4. B 的 OADEV@100 0.2476 vs A 0.3715；
5. B 的 OADEV@200 0.1798 vs A 0.3638；
6. 4 个窗口里 B 全部优于 A；
7. B 的相位卡在 -2744 ns，A 回到 0 附近；
8. B 的 DAC 动作减少（std 2.15 -> 0.77）。
```

### 必须注明

```
1. 只有一对 A/B，没有重复；
2. t=600 时两段相位工作点不同；
3. B 的相位偏移是预期代价，不是故障；
4. OADEV@100 改善 33% 远超预测的 1%；
5. 所有指标相对本机 GNSS PPS。
```

### 不能写

```
- 相位项没用（它在 A 里确实把相位拉回了 0）；
- B 全面更好（相位偏移 2.7 微秒是实打实的代价）；
- 改善幅度可外推（只有一对）；
- 33% 是确定值（单次测量）。
```
