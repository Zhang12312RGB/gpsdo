## 四、⭐⭐ 模型比较：排序**不稳定**

### ⚠️ log 变换的偏差问题

```
log(R) = a + b·x  →  预测时直接 exp(a+b·x)
        ↓
E[R] ≠ exp(E[log R])    （Jensen 不等式）
        ↓
必须在原尺度修正
```

**训练 131 / 验证 34（大天线）**

| 方法 | 验证 RMSE | 偏差 | 排序 |
|---|---|---|---|
| **对数正态 exp(σ²/2) 修正** | **13.95** | −3.10 | **1** |
| Duan smearing 修正 | 14.53 | −5.11 | 2 |
| **常数 R** | **14.93** | −6.26 | **3** |
| log 直接 exp | 16.71 | −9.71 | 4 |

**σ² = 0.3358，smearing = 1.127**

```
⚠️ 我上一版用【未修正的 exp】→ RMSE 13.23，常数 12.28
   → 结论「常数 R 胜出」✗

   修正后：对数正态 13.95 < 常数 14.93
   → 排序【反了】
        ↓
【不能据此确定模型优劣】
```
