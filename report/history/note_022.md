## 八、能写 / 不能写

### 可以写

```
1. 四段闭环门控零异常；
2. OADEV@100：开 0.3159，关 0.2225（-29.6%）；
3. OADEV@200：开 0.2923，关 0.1536（-47.5%）；
4. 4/4 逐对比较全部为关闭版更好；
5. τ<=50s 改善只有 6~10%，τ>=100s 改善 30~50%；
6. 关版滑窗离散 1.74/2.34，开版 2.30/3.54；
7. 两次开启相位 +9/+8 ns，两次关闭 -2744/-2824 ns。
```

### 必须注明

```
1. 每侧只有 2 段，样本仍少；
2. 改善幅度在 19%~65% 之间（逐对），有较大离散；
3. 相位偏移是预期代价，不是故障；
4. 滑窗高度相关，不能当独立样本；
5. 所有指标相对本机 GNSS PPS。
```

### 不能写

```
- 改善精确等于 47.5%（会随窗口变）；
- 短 τ 也改善（只有 6~10%）；
- 可以直接外推到其它 OCXO。
```
