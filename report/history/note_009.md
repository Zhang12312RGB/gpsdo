## 二、可以下的结论

### 结论 1：K_PHASE 减半后，稳态 DAC 抬高 138 码

   1881 → 2019（+138 码，相当于工作点偏 +66 ppb）

**直接读数，可靠。** 小增益把工作点推向更高的 DAC，与「相位反馈减弱 → 需要更多频率项补偿」的直觉一致，但本轮无法判断利弊。

### 结论 2：冻结段质量强烈依赖工作点

   冻结 DAC = 1886（工作点）   → ppsm 段间 0.70 ppb
   冻结 DAC = 2008（偏 256 码）→ ppsm 段间 5.62 ppb
   冻结 DAC = 2011（v8）       → ppsm 段间 12.2 ppb

**三个独立观测的一致趋势，指向同一现象：OCXO 偏离 1886 后低频漂移变大。** 但只有 3 点、单次观测，不能定量。

### 结论 3：v9 的反向冻结同样有效

v9 冻结段（DAC=2008）段间 5.62 ppb，同时段闭环 6.73 ppb —— **冻结没有比闭环更干净**。

这不是失败，而是有效信息：在偏 256 码的工作点上，固定 DAC 本身就在漂，冻结对照失去区分能力。

## 三、关于「600 秒周期」的更正

**初版第三章写「慢环 300 秒窗口与相位环 200~500 秒耦合形成 600 秒振荡」，这一整段作废。**

### 为什么作废

```
v7：2493 条，fmod 全 0、fsrc 全 0、fw 全 0
v9：2655 条，fmod 全 0、fsrc 全 0、fw 全 0
        ↓
【慢环完全没有参与控制】
        ↓
不加入慢环项，已能重放全部整数 DAC 命令
        ↓
「慢环与相位环耦合」没有物理基础
「改慢环窗口」也就没有控制依据
```

### 第二个问题：周期本身没有确认

```
5.64 / 6.73 / 0.70 / 5.62 ppb
        ↓
都是【6 个 100 秒块均值的 max-min】
        ↓
只描述【幅度】，不含【周期信息】
一次单调漂移或单次恢复过程也能给出这些数字
        ↓
我没做频谱分析就说「周期 600 秒」，不成立
1/K_PHASE 在特定假设下可近似描述【恢复时间尺度】，不是振荡周期
```

### 冻结仍漂，也不能唯一归因于 OCXO 工作点

```
v9：DAC 停止变化后，相对频差仍有慢变
        ↓
可能原因（尚未区分）：
  - OCXO 本身
  - EFC 电压 / 供电
  - 此前控制动作的迟滞
  - GNSS 参考（同一接收机也不能保证前后时段误差相同）
  - 测量链
```

**另：2008 相对 1886 差 122 码；256 码是相对初始化码 1752。**

## 四、修改方案（按审计调整后）

| 方案 | 状态 | 理由 |
|---|---|---|
| **加 DAC 偏置对齐 1886** | ❌ **暂不做** | **真实偏置会改变 EFC 电压**；只改显示没有物理作用；积分闭环还可能把人为偏置抵消 |
| **改慢环窗口 / 继续降 K** | ❌ **暂不做** | **慢环未参与控制**，周期也未确立 |
| **多工作点冻结** | ✅ **保留，改往返顺序** | 用 **A→B→A** 而非单向 A→B→C，才能核对同码重复性、分离时间漂移 |
| **暂缓调 R / Q** | ✅ **同意** | 高 z² 不能单独定位到 R |

### 下一步的真正优先项

```
核查「实际 DAC 码值 → EFC 电压 → 相对频差」的响应和重复性
        ↓
再决定反馈参数（R / Q / K_PHASE）
```

**1886 是历史观测到的码值，不应成为控制目标。**

### 往返冻结实验的具体设计

```
顺序：A → B → A
每段：稳定后采 20 分钟
  A = 1886（历史工作点）
  B = 1950 或 2020（偏离点）
        ↓
比较：
  A1 与 A2 的漂移率差异  → 时间漂移有多大
  A 与 B 的漂移率差异    → 工作点的影响有多大
```
