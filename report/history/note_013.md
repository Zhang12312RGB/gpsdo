## 三、⭐ 关键发现：X[1] 不能当作相位导数

### 3.1 原因：X[1] 含 DAC 输入补偿

`main.c:436-444`：

```
du = (cur_dac - prev_dac) * DAC_GAIN * loop_sign;
X[1] += du;        // DAC 阶跃直接加到频率估计
```

所以：

```
X[1] = 上一拍估计 + DAC补偿 + 新息修正
        ↓
DAC 减 1 码 → du = -0.47852 → X[1] 被拉低
但新息仍为正 → 相位被拉高
        ↓
【两条曲线可以反向】
```

### 3.2 实测：原始通道与 X[1] 的失配

**t=3800~3960 秒（160 秒）：**

| 项 | 复算值 | 审计值 |
|---|---|---|
| **原始累计相位增量** | **+297.07 ns** | +275.20 ns |
| **整数计数贡献** | **+300 ns** | +250 ns |
| **原始平均频差** | **+1.857 ppb** | +1.720 ppb |
| **同期 X[1] 均值** | **+0.291 ppb** | +0.264 ppb |

**→ X[1] 比原始通道小 1.57 ppb**

**→ 整数计数贡献 101% —— 不能归因于 TDC 细分**

### 3.3 X[1] 下降而 phs 上升的实例

| t | X[1] | phs (ns) | dDAC |
|---|---|---|---|
| 3830 | 0.444 → 0.046 | −33.1 → −25.4 | **0** |
| 3890 | 0.665 → 0.371 | 50.7 → 71.3 | **0** |
| 3910 | 0.528 → 0.198 | 90.9 → 106.4 | **0** |
| 3930 | 0.341 → 0.004 | 122.8 → 135.8 | **0** |

**→ 四次都是 dDAC = 0，所以不是 DAC 补偿造成的** ⚠️

**→ 是新息造成的 —— 需逐拍重放才能完全解释**

### 结论 3

**X[1] 接近零不足以判断已经锁定。**

**必须以原始测量通道（`raw × 0.1953125`）为准。**
