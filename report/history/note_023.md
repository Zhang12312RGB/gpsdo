## 七、能写 / 不能写

### 可以写

```
1. 四段闭环门控零异常；
2. @200s：开 0.2923，关 0.1536（-47.5%）；
3. @2s 恶化 +17.7%，@5s 恶化 +41.2%；
4. @100s 改善 -29.6%，@200s 改善 -47.5%；
5. 两次关闭相位都在 -2700~-2900 ns；
6. 关闭版 DAC 变化更频繁但幅度更小。
```

### 必须注明

```
1. 每种设置只 2 次运行，4/4 是交叉比较不是独立验证；
2. -2.8 微秒是相对软件零点的累计偏移；
3. 稳定度改善不代表平均频差改善；
4. 2~5 秒有代价，不是全面改善；
5. 所有指标相对本机 GNSS PPS。
```

### 不能写

```
- 短 τ 几乎不受影响；
- 相位项只注入低频噪声；
- 4/4 是四次独立验证；
- -2.8 微秒是 UTC 时间误差或固定代价；
- 全面改善。
```
