## 五、🔴 关键问题：`0x00` 与 `0x18` 差一个 LSB

### 现象

理论上应有：
```
0x00 = (0x18 << 8) + f
```

实测：
```
不一致样本：311 / 881（35.3%）
差值恒为【−256】（恰好一个 0x00 LSB）
```

### 样例

| `0x00` | `0x18` | `f` | 期望 `(0x18<<8)+f` | 差 |
|---|---|---|---|---|
| 72 | **1** | 72 | 328 | **−256** |
| 51 | **1** | 51 | 307 | **−256** |
| −76 | **0** | 180 | 180 | **−256** |
| −1 | **0** | 255 | 255 | **−256** |

### 含义

```
0x18 是【纯整数路径】的结果（ocxo_delta）
0x00 是【整数+分数】的结果（ocxo_delta_frac >> 8）
两者在 35.3% 的样本上差恰好 1 个 LSB
        ↓
说明整数项的舍入方向不一致
（一个用 floor，一个用 round 或 ceil）
```

**→ 这不影响环路（PS 只读 `0x00`），但会影响诊断判断** ⚠️
**→ 如果以后用 `0x18` 做交叉校验，会得出错误结论** ⚠️

```

|Δ0x00| 最大 = 198 LSB = 38.7 ns
```
