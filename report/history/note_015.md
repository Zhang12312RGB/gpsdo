## 五、CALIB 的 phsm/frqm 为什么冻结

```
task_calib_second() 只做三件事：
  z     = read_phase_error_ns();
  innov = z - kalman.X[0];
  adaptive_r_update(hdop, sat, cn0, innov);
        ↓
没有 kalman_update()，没有改 X[0]/X[1]
        ↓
日志打印的是 kalman.X[0]，当然一秒都不变
```

**不是坏了，是 CALIB 本来就不跑 KF 更新。**

### 真正要修的是 R 的训练口径

```
当前:  innov = 每秒相位增量(ns/s) - 累计相位状态(ns)
                              ↑                    ↑
                         量纲不一致
        ↓
不能据此标定四个系数
```
