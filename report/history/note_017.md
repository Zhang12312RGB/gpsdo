## 五、能写 / 不能写

### 可以写

```
1. 门控在 3525 秒内零误触发；
2. A 段基准：X[1] std = 0.2645 ppb；
3. 原始 OADEV@100 = 0.3715，@200 = 0.3638 ppb；

5. 相位累计 101.0 ns / 2925 秒；
6. 全轮 phsg=1。
```

### 必须注明

```
1. 这是 A 段基准，单独看不能证明相位项有用/无用；
2. 相位项强度必须用 RMS，不能用均值；
3. t=600 是 A/B 统一窗口，不是物理收敛点；
4. 长 τ OADEV 不确定性随 τ 增大；
5. 所有指标相对本机 GNSS PPS。
```

### 不能写

```
- 相位项只占 0.30（均值比，错的）；
- 稳态从 t=480 开始；
- τ=600 只有 4 个差分项；
- B 段应达到 0.143 ppb（v14 模型预测，不是验收线）。
```
