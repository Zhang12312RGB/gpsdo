## 四、需要说明的三点

### 4.1 峰只是被压低并右移，没有消除

```
旧: 峰 0.606 @ 64 s
新: 峰 0.334 @ 128 s
```

这是相位反馈项的一阶时间常数（1/K_PHASE）造成的。
只要保留这一项，峰就会存在，只能移动它。
想彻底消除，需要让积分器主导（去掉或大幅减小 K_PHASE）。

### 4.2 启动瞬态没有变长 —— 我的预判错了

```
旧: phs 峰峰 0.25 us
新: phs 峰峰 0.24 us
```

我预判"降增益会让瞬态变长 4 倍"，实测没有发生。
原因：瞬态主要来自 DAC 的初始跳变，不是相位反馈的收敛速度。

### 4.3 phs 稳态标准差 25 ns

比 1PPS 抖动（约 5 ns）大 5 倍，说明相位锁定还有提升空间。

## 五、可以写进报告的结论

### 可以写

```
1. 稳态 Allan@1s = 0.0720 ppb，@600s = 0.0380 ppb；
2. K_PHASE 从 0.02 降到 0.005 后：
   - Allan@1s 改善 22%，@64s 改善 48%，@512s 改善 34%；
   - 稳态 frq 标准差 0.208 ppb，dac 1736.3 +- 0.54 码；
   - 相位误差稳态标准差 25 ns；
3. 峰值位置 64 s 移到 128 s，与 1/K_PHASE 的预期一致；
4. 启动瞬态未因降增益而变长；
5. 两次采样 PL 版本相同，唯一改动是 PS 侧 control.h 的一个参数，可直接对比。
```

### 必须注明

```
1. 峰仍存在（0.334 @128s），只是被压低并右移，未消除；
2. n>=2 的比例从 36.1% 降到 24.5%，慢环参与度下降，
   改善主要来自快环本身而不是融合；
3. 「Allan 偏差」描述的是滤波估计序列 X[1]，
   不是实物 OCXO 输出的独立稳定度；
4. 两次采样的环境温度、GNSS 卫星数不同；
5. 只做了 1 次参数变更，缺少重复性验证。
```

### 不能写

```
x Allan 随 tau 单调改善（128 s 处仍有 0.334 的峰）；
x 慢环贡献了大部分性能（n>=2 只占 24.5%）；
x 已达到 0.039 ppb 稳定度（那是分辨率）。
```
