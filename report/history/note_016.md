## 五、能写 / 不能写

### 可以写

```
1. 门控在 3525 秒内零误触发；
2. 稳态段 3045 秒，X[1] = 0.030 ± 0.357 ppb；
3. OADEV: τ=100 0.3680，τ=200 0.3585 ppb；
4. 相位累计 +236.9 ns / 3045 秒，拟合斜率 −0.0087 ppb；
5. DAC 稳定在 1879（范围 1876~1886）；
6. 全部 3525 秒 phsg=1（相位项开），可用作 A 段基准。
```

### 必须注明

```
1. 本段是【A 段基准】，需与 B 段（相位项关）等长对比才有意义；
2. 稳态起点 t=480 是判据选出来的，不是物理上的明确时刻；
3. OADEV 用 REFCHK raw，不是日志里的 phsm；
4. τ > 600 秒不可信（重叠项太少）；
5. 所有指标相对本机 GNSS PPS，非独立外部校准。
```

### 不能写

```
- 相位项有用/无用（要等 B 段才知）；
- 比 v13 改善了（窗口不同）；
- 稳态从 t=480 精确开始（是判据选的）；
- τ=600 的 0.1365 可信（重叠项只有 4 个）。
```
