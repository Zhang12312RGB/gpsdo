## 下一步优先方向

### 优先 1：处理时间滞后，先计算候选权重，不马上接入反馈

去掉已知 DAC 动作后，fRef 仍然是历史窗口的频率。图中满窗口结果的 lag 约为 **300～530 秒**；它与“距离上次拟合端点的 age”不同。旧融合模型按固定 T/2=150 秒估算滞后，不适合直接用于这些 C 候选。

建议下一版先增加只记录的权重计算，用实际样本时间和 lag 评估不确定度：

```text
候选慢环方差 = 拟合测量项 + (漂移率×实际 lag)² + 增益等模型误差项
```

先观察候选权重是否随着结果变旧合理下降，再决定反馈比例。漂移率本身仍需数据标定，不能把当前经验系数当成精确物理常数。

### 优先 2：同窗口比较，分清历史滞后与估计失配

不能只用历史 fRef 与当前快环参考频率比较，就把全部差异归于算法偏置。图中做了一个近似分解：把每 10 秒的快环参考频率保持并积分成相位，再对相同采样时刻拟合，与 C 的 fRef 比较。

例如 t=1349 的 599 秒拟合，C 与近似同窗口快环参考频率只差约 **−0.0054 ppb**；而随后当前时刻的平均差约 **+0.1189 ppb**。这支持该段差异主要与历史窗口和当前时刻不一致有关。其他窗口仍有同窗差异，不能用这一例排除增益或模型问题。

近似分解不是独立真值，也不是新的闭环试验；全段差值与 lag 的简单相关系数约 -0.092，因此不建议仅凭四次拟合就拟合一个统一的线性“年龄补偿斜率”。

### 优先 3：核实工作点增益和测量时刻，再做 B/C 反馈对照

在当前 1885～1887 附近核实 DAC_GAIN，检查模型命令时间与相位观测时间是否对应。积分率与代码中同一个 g 公式吻合，只证明内部计算一致，不能独立标定实际模拟增益。

继续积累多个完整 600 秒滚动窗口，并保持一致预热条件。估计一致性和候选权重得到支持后，再单独开启 C 反馈，与 B 比较相同窗口的原始测量 Allan、相位、DAC 动作及外部参考测量。当前 C 没有控制系统，不能将本轮 Allan 改善归功于 C 补偿反馈。

R/Q 和 K_PHASE 暂不作为这一阶段的首个修改变量。如果后续主要目标转为缩短开机收敛，再把获取阶段的增益调度作为独立实验研究，不要与首次 C 反馈试验同时改变。
