# 历史分析与纠错记录

note_*.md保留实验当时的分析、猜测与纠错，不作为当前配置或最终性能表。编号与原文件的对应关系见[文件来源表](../../docs/file_map.csv)。

阅读时需区分假设、已被后续记录推翻的判断和最终结论。旧记录中的10 MHz、早期器件称呼、在线R训练状态、单一慢变归因及未重复的收益不能自动沿用到提交版。

当前采用20 MHz OCXO、DAC8531、固定R80/Tu10、相位回零关闭和受限C慢环MODE2。长期收益的证据范围及最终固件功能验收见[证据表](../../docs/evidence_map.md)。

未随本提交包分发；与其相关的数值结论可在同一 note 的文字及 data/results 中找到。
