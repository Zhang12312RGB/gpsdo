```

        ↓
【有正有负，不是单调】
        ↓
所以至少一部分来自【GNSS 参考自身的慢变】
```

## 七、能写 / 不能写

### 可以写

```
1. 门控在 3253 秒内零误触发（why 全 0，bad/gapfill/gapskip/hreset 全 0）；
2. 闭环末 1200 秒累计漂移 +7.4 ns（0.006 ppb），OADEV@100 = 0.265 ppb；
3. 冻结 1381 秒累计漂移 +1238.3 ns，线性拟合 1.059 ppb；
4. 冻结 OADEV@100（去趋势）= 0.359 ppb；
5. 冻结段漂移不单调：1.007/0.880/1.245/1.163/-0.278 ppb，最后 181 秒反转；
6. `lag = age + span/2` 精确成立（差 0~1 秒）；
7. CALIB 的 `phsm`/`frqm` 不更新（全程 -5593 ps / -18），必须用 REFCHK。
```

### 必须注明

```
1. 本轮无自然故障，拒绝/恢复路径只经离线验证；
2. CALIB 的 phsm/frqm 是冻结值，任何冻结段分析都要用 REFCHK raw；
3. 冻结段有 1.06 ppb 线性趋势，OADEV 需去趋势后才能比；
4. 漂移不单调 -> 不能全部归因于 OCXO 老化；
5. 所有指标相对本机 GNSS PPS，非独立外部校准；
6. C 的 lag 是锯齿，不是单调增长。
```

### 不能写

```
- 慢变来自 OCXO 老化（漂移有正有负，不单调）；
- CALIB 的 phsm = -5593 ns（单位是 ps，实际 -5.593 ns）；
- lag 持续扩大（锯齿，每 300 秒回落）；
- lag 均值 192 秒（那是含无效记录的错算，v=1 只有 406 秒）；
- 门控能挡住真实故障（本轮没触发过）；
- SLOW_DRIFT_PPB_S=2e-4 可信（实测漂移率约 9.5e-4，差 4.7 倍）。
```
