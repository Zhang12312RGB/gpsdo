## 四、phase_ref 为什么不能兼得

```
phase_ref 只改变控制目标：
  相位项 = K_PHASE * (X[0] - phase_ref)
        ↓
但 K_PHASE 不变
        ↓
相位起伏仍以相同增益进入控制
        ↓
不能自动得到 B 的稳定度
只是不再强迫回到 0，避免 2.7 微秒偏移
```

## 五、能写 / 不能写

### 可以写

```
1. A/B 只改了 EXP_PHASE_TERM_EN 一个变量；
2. 两段门控零坏样本；
3. t=600~3524：B 的 OADEV@200 0.1798 vs A 0.3638；
4. 但同配置的 v14 是 0.1614（t=600~1870），比两者都好；
5. v15 自身滑窗离散 3.54 倍，v16 是 2.34 倍；
6. B 的相位卡在 -2744 ns；
7. B 的 DAC 变化次数 138 vs A 74。
```

### 必须注明

```
1. 只有一对 A/B，需补 A2 复测；
2. v14 和 v15 同为开启却差 2.85 倍，单次测量重复性有限；
3. 滑窗高度相关，不能当独立样本；
4. 平均频差必须用原始通道，不是 X[1]；
5. v12/v13/v14 的 phsg 应记为未知，不是 0。
```

### 不能写

```
- 关闭相位项必然更好（v14 开反而更好）；
- 改善 33%/50% 是确定值（单对，且同配置差 2.85 倍）；
- 四个嵌套窗口算四次独立验证；
- phase_ref 能兼得两者；
- 平均频差用 X[1] 均值。
```
