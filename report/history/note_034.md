## 五、⚠️ 需要注意的问题

### 5.1 长 τ 性能反而变差

```
τ=1s    0.0515  ✅ 好
τ=10s   0.1204  ⚠️
τ=100s  0.1817  ⚠️ 随 τ 上升
τ=200s  0.1987  ⚠️
```

**→ 正常的白相位噪声应该让 Allan 随 τ 下降（∝1/√τ）**
**→ 这里反而上升，说明有【慢变系统误差】或【环路本身的低频漂移】**

**可能原因：**
1. `K_PHASE = 0.02` 的相位反馈引入了低频振荡
2. 慢环的 300 秒最小二乘输出有滞后（T/2 = 150 s）
3. `dac` 的 ±0.73 码抖动（0.35 ppb）在长 τ 处积累

### 5.2 逐秒相位抖动 7.6 ns

```
0x00 标准差 = 7.6 ns
理论量化（39 ps/√12）= 0.0113 ns
→ 差 670 倍
```

**自相关分析**：lag=1 为 −0.21，lag≥2 接近 0 → **白噪声**
**与 `tap` 的相关系数** = −0.08 → **不相关**

**→ 最可能是 `ocxo_in` 的 2 级同步器亚稳态（±1 拍 = ±10 ns）**
**→ 修它需要第二个 TDC 测 OCXO 边沿的亚周期位置**

### 5.3 日志显示格式

```c
c = pe / 256;      // 向零截断
f = pe & 0xFF;     // 补码低 8 位
// 负值时 c*256+f ≠ pe，拼不回去
// 应改为 c = pe >> 8（算术右移）
```

**→ 只影响日志可读性，不影响控制**
