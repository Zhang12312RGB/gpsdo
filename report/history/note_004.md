## 八、能写 / 不能写

### ✅ 可以写

```
1. 固定 T=10 的配置已生效验证（1913 条 T=10，200 次 Tu=10）
2. 舍入偏差 +0.002266 ns/秒，比截断版（-0.078115）改善 34 倍
3. 稳态 frq = 0.016 +- 0.483 ppb，dac = 1884.9 +- 1.11 码
4. 稳态 Allan@1s = 0.0456 ppb，@100s = 0.3164 ppb
5. n>=2 占比 66.68%，n=3 占 51.1%
6. z^2 分阶段：启动 67.75 / 300-1200 2.76 / 稳态 3.15
7. 固定 T=10 在所有 tau 上都比自适应 T 差 25%~89%
```

### ⚠️ 必须注明

```
1. 只有 1983 秒，稳态段仅 783 秒；
2. 固定 T=10 变差说明「消除周期切换」不是改进方向，
   但自适应切换在补偿什么，本轮数据无法确定；
3. 慢环事件次数与上一轮几乎相同，说明事件率与 T 无关；
4. 「Allan」描述的是 X[1] 估计序列，不是实物输出稳定度。
```

### ❌ 不能写

```
x 固定周期能改善长 tau（实测反而变差 36%）；
x Tu 切换是 Allan 上升的主因（固定后照样上升）；
x z^2 = 3.15 说明 R 需乘 3.15（只说明 S 方差约低估 3.15 倍）。
```
