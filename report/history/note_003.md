## 四、仍然存在的问题

### 4.1 🔴 Allan 随 τ 上升

```
τ=1s    0.0352
τ=10s   0.0739
τ=100s  0.2332  <- 上升 6.6 倍
```

**正常的白相位噪声应该是 ∝1/√τ 下降。**

**可能原因：**
1. 控制环工作点 `dac = 1888` 离中心 1752 有 136 码（+65 ppb），处于非线性区
2. `Tu` 在 1/5/10 秒之间切换，`Q = Q_FREQ × T` 随之变化，造成非平稳
3. 慢环 300 秒窗口与快环的时间常数耦合

### 4.2 🟡 `z²` 均值 3.30（理想 1）

| `|z|` | 次数 | 占比 |
|---|---|---|
| >1 | 332 | 53.1% |
| >2 | 127 | 20.3% |
| >3 | 48 | 7.7% |
| >4 | 28 | 4.5% |
| **>5** | **14** | **2.2%** |

**→ 如果 R 模型正确，5σ 应该只出现 0.00006%，实测 2.2%**
**→ 说明 `S` 偏小约 3.3 倍（√3.30 = 1.82）**

### 4.3 🟡 控制周期在三种值之间跳

| `Tu` | 次数 | 占比 |
|---|---|---|
| **1 s** | 370 | 58.3% |
| 5 s | 119 | 18.7% |
| 10 s | 146 | 23.0% |

**→ 每次切换都改变 `Q = KALMAN_Q_FREQ × T`，`P3` 会突变**
**→ 这是 Allan 在中等 τ 处上升的可能原因之一**

### 4.4 🟡 `R` 变化范围很大

```
R: 10 ~ 129 ns²   均值 44.2   标准差 22.3
```

**→ 自适应 R 在工作，但变化 13 倍会影响卡尔曼增益的稳定性**

```

2. 标准化新息平方均值 3.30，说明 S/R 模型偏乐观约 1.8 倍；

4. 真正稳态需要 1200 秒才达到，前 20 分钟的数据不能用于长 tau 分析；
5. 「Allan」描述的是滤波估计序列 X[1]，不是实物 OCXO 输出的独立稳定度。
```
