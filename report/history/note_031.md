
## 标签生成（采集后）

**用 REFCHK raw，不用 CALIB 的 phsm/frqm：**

```
phase(t) = Σ raw × 0.1953125        （逐秒累加）

每段内取【不重叠 40 秒窗口】
  ↓
phase = a + b·t + 残差               （拟合去掉窗口内常频偏移）
  ↓
R_label = SSE / (N - 2)
  ↓
配对窗口的 HDOP / SAT / CN0（同一时段的均值）
```

**窗口排除条件：**

| 排除 | 原因 |
|---|---|
| 跨位置切换 | 相位参考可能跳 |
| 跨测量缺口 | 时间轴不连续 |
| 跨 DAC 变化 | 频率阶跃 |
| `SAMP why != 0` | 测量无效 |
| `fresh = 0` | GGA 不新鲜 |
| 定位无效 | |
| HDOP = 99.99 等 | 无效值 |

**⚠️ 不设 `sat >= 8` 筛选** —— 那会把「较差但仍有效」的条件全删掉

## 模型比较

**常数 R vs 四参数：**

```
log(R) = β0 + β1·HDOP + β2·SAT + β3/CN0
```

**检查：**

| 项 | 怎么看 |
|---|---|
| 特征覆盖 | 三个自变量的范围是否够宽 |
| 矩阵秩 | 是否共线 |
| 条件数 | 是否病态 |
| **留出验证** | **按条件段/时间块，不随机打散** |

**判据：**

```
如果四参数对留出数据【没有稳定优势】
        ↓
【保留常数 R=80】
【不强行输出四个数】
```

## ⚠️ 两条边界

### ① 小天线训练的系数不能直接用于大天线

```
天线、电缆、多路径都会影响授时误差
        ↓
第 5 段（大天线）只用于【初步检查能否迁移】
        ↓
【两种天线分别标记、分别检查】
```

### ② CALIB 标签不等于纯测量噪声

```
残差仍含：OCXO 窗口内变化 + GNSS + TDC + 相关噪声
        ↓
必须在【独立 TUNING 记录】里验证
        ↓
不能仅凭 CALIB 标签直接改 R
```
