# GPSDO A/B 对照实验报告：慢环融合是 100 秒波动的主因

> **实验设计**：唯一变量 `EXP_SLOW_CONTROL`，其余完全相同  
> A 版：`桌面\data\2026-10-28_v2_A版_固定T10_慢环开.dat`（784 KB，1983 秒）  
> B 版：`桌面\data\2026-10-28_v3_B版_固定T10_慢环关.dat`（776 KB，1969 秒）  
> 共同配置：`EXP_FIXED_PERIOD=1`（T=10 s）、`K_PHASE=0.005`、同一套 R/Q/门限  
> 分析窗口：**t ≥ 1200 s**（真正稳态，A 783 秒 / B 769 秒）  
> 报告生成：2026/10/28 13:12:38

## 一、核心结论

**慢环融合在 100 秒尺度上注入了波动。关掉后 `Allan@100s` 改善 7.3 倍。**

| τ | **A 版（慢环开）** | **B 版（慢环关）** | 变化 |
|---|---|---|---|
| 1 s | 0.0456 | 0.0709 | **+55%** ❌ |
| 2 s | 0.0646 | 0.1003 | +55% ❌ |
| 5 s | 0.0986 | 0.1593 | +61% ❌ |
| 10 s | 0.1399 | 0.2231 | +59% ❌ |
| **20 s** | 0.1525 | **0.0805** | **−47%** ✅ |
| **50 s** | 0.2363 | **0.0670** | **−72%** ✅ |
| **100 s** | **0.3164** | **0.0431** | **−86%** ✅✅ |

**→ 交叉点在 τ ≈ 15 s**  
**→ 短 τ 变差（慢环关掉后快环独担），长 τ 大幅改善**

## 三、机理：为什么慢环会注入 100 秒波动

```
慢环用【过去 300 秒的相位斜率】算 slow.freq
        |
但这 300 秒里，DAC 已经改变了 OCXO 的频率
        |
slow.freq 里混进了"我们自己造成的频率变化"
        |
以最高 89% 的权重进入 f_ctrl
        |
继续推 DAC，改变下一个 300 秒的相位
        |
【正反馈，周期约 100~300 秒】
```

**这与 10-28 审计的判断完全一致：**

> "目前慢环使用过去几百秒的相位斜率，而 DAC 在这期间已经改变了 OCXO 频率。
> 这个历史平均频率直接参与当前控制，可能继续推动 DAC，造成慢变化或往返调整。"

**→ 本轮 A/B 实验给出了直接证据** ✅

## 四、DAC 动作对比（稳态 783/769 秒内）

| 版 | DAC 变化次数 | 范围 | 标准差 |
|---|---|---|---|
| A | **15 次** | 1883~1887 | 1.11 |
| B | **34 次** | 1884~1886 | **0.68** |

**→ B 版 DAC 动得更频繁（34 vs 15），但幅度更小（std 0.68 vs 1.11）**  
**→ 快环在密集微调，而 A 版是「少但大」的跳变**  
**→ A 版的 15 次大跳变正是慢环推动的**

## 五、代价与权衡

**关掉慢环不是免费的好处：**

| 收益 | 代价 |
|---|---|
| ✅ `Allan@100s` 改善 7.3 倍 | ❌ `Allan@1s` 变差 55% |
| ✅ `frq` 标准差 −60% | ❌ `Allan@2~10s` 变差 55~61% |
| ✅ `dac` 标准差 −38% | |

**→ 慢环的价值在长 τ，但当前实现把长 τ 弄得更差**  
**→ 正确的方向不是关掉它，而是修正它**

## 六、下一步：慢环补偿 DAC 动作

```
现在:  slow.freq = 过去 300 秒相位斜率

改进:  (1) 从历史相位中【扣除 DAC 控制造成的相位】
       (2) 再估计 OCXO 自身的漂移
       (3) 换算到当前 DAC 工作点
```

**具体做法：**

```
每个采样点的相位 phi_i 含有两部分:
  phi_i = phi_drift,i + phi_control,i

phi_control,i = sum_{j<i} (dac_j * DAC_GAIN) * (t_i - t_j)
  （已知量：DAC 每次变了多少码、什么时候变的）

所以:  phi_drift,i = phi_i - phi_control,i

慢环改为对 phi_drift 做最小二乘，而不是对 phi
```

**→ 这样慢环只看到"OCXO 自己的漂移"，不会把自己造成的动作当成外部变化**

**不是**：缩短窗口、增大门限 —— 那些只是治标

## 七、能写 / 不能写

### ✅ 可以写

```
1. A/B 对照实验完成，唯一变量是 EXP_SLOW_CONTROL；
2. 慢环关掉后 Allan@100s 从 0.3164 降到 0.0431（改善 7.3 倍）；
3. 慢环关掉后 frq 标准差从 0.483 降到 0.191（-60%）；
4. 慢环关掉后 dac 标准差从 1.11 降到 0.68（-38%）；
5. 但短 tau（1~10 s）变差 55~61%，是真实的权衡；
6. 两版的相位都锁在 0 ns 附近，没有失控；
7. 机理：慢环的 300 秒窗口里混入了 DAC 自己造成的频率变化。
```

### ⚠️ 必须注明

```
1. 两版各只有约 2000 秒，稳态窗口 769~783 秒；
2. B 版 n>=2 占比 100% 是因为慢环仍在计算（只是不参与），
   不能说明"融合生效"；
3. 两轮的 GNSS 条件（卫星数、HDOP）略有不同，未做严格同时性对照；
4. "Allan" 描述的是 X[1] 估计序列，不是实物 OCXO 输出的独立稳定度；
5. 只有一轮 A/B，缺少重复性验证。
```

### ❌ 不能写

```
x 关掉慢环是最终方案（短 tau 明显变差）；
x 慢环融合没有价值（它的价值在长 tau，只是当前实现有缺陷）；
x 已经找到慢环缺陷的完整修复（补偿方法尚未实现和验证）。
```
