## 三、⚠️ 时间对不上的两处

### ① 段 1→2 的移动时刻

```
你说：14:42 移到 B′
数据：ms=2,197,000（= CALIB 第 21.0 分钟）

但数据在 ms=1,477,000（第 9 分钟）就出现 SAT 7→8、HDOP 1.38→1.08
        ↓
那可能是【卫星几何变化】，不一定是移动
```

### ② 质量是渐变的

```
CN0: 31 → 34 → 31 → 30 → 27 → 23 → 28 → 25 → 24 → 25 → 23 → 27 → 22 → 22 → 21
        ↓
没有干净台阶，从第 11 分钟起缓慢下降
        ↓
【段的划分只能按你说的时刻，不能靠数据自动切】
```

**→ 结论：段边界按操作时刻，但标签必须用【逐窗口实测的 HDOP/SAT/CN0】**

## 六、标签生成

```
phase(t) = Σ REFCHK.raw × 0.1953125      （逐秒累加）

每段内取【不重叠 40 秒窗口】
  ↓
phase = a + b·t + 残差
  ↓
R_label = SSE / (N - 2)
  ↓
配对同窗口的 HDOP / SAT / CN0 均值
```

**窗口排除：**

| 排除 | 原因 |
|---|---|
| 跨节点 | 相位跳变 |
| 跨测量缺口 | 时间轴断 |
| 跨 DAC 变化 | 频率阶跃（本轮无）|
| `SAMP why != 0` | 测量无效 |
| `fresh = 0` | GGA 不新鲜 |
| `fix = 0` | 无定位 |
| `HDOP > 3` | 几何差 |
| 前 60 秒 | 切换瞬态 |

**⚠️ 不设 `sat >= 8` 筛选**
