# R的非线性模型：可尝试，但当前收益尚不足

2026-10-31。复用之前同一版本、同一筛选规则的371个新门控40秒相位残差标签，其中CALIB200窗、闭环稳定DAC171窗。输入SHA与联合分析清单逐一核对。仅离线分析，未改变运行程序、R、慢环或采集过程。

可以使用非线性模型。Pearson相关接近零只表示线性相关弱，并不能排除U形、阈值、饱和或交互作用。此前R0+k·10^((30−CN0)/10)、R0+k·HDOP²已经对输入非线性，只是对待估系数仍线性；这次进一步让曲率、指数或转折点从训练数据估计。

## 模型

令C为CN0，x=(C−30)/10：

1. 二次曲线：R=a+b*x+c*x²，3个系数，可表示U形或倒U形。
2. 带底噪自由指数：R=R0+A*10^(p*(30−C)/10)，R0、A、p共3个参数，非负，p限制在0.05～3；包含常数退化情形A=0。
3. 饱和曲线：f=1/(1+exp((C−Cmid)/3))，R=Rgood*(1−f)+Rweak*f。拟合Rgood、Rweak、Cmid共3个参数，宽度固定3 dB、转折点限定15～45 dB-Hz。这里允许两端方差任意高低，仅作经验模型，不强加弱信号方差更大。
4. 收缩二次曲线：同样3个系数，另有正则化强度；只在外层训练实验内再次按实验留出选择λ，候选0、1、10、100、1000。λ属于调节复杂度的超参数，不能假装不存在额外选择步骤。

非线性函数按窗口内每秒CN0计算，再用局部直线回归残差的杠杆权重平均；不是简单把平均CN0代进曲线。输出比较时统一限于10～50000 ns²，并同时保存未限幅的误差；本次两个误差相同，结果没有靠限幅“救回来”。

指数与饱和形状采用有界的一维形状搜索和非负线性分量拟合，属于变量投影。二次曲线对输入非线性，但参数可用线性最小二乘；不是所有非线性都需要神经网络。数值方法参见[SciPy有界非线性最小二乘](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)。

## 按整轮留出的验证

每次整轮实验不进入对应训练集；同轮相邻窗口不随机分到训练和测试。正则化的选择也限制在训练实验内，方法参见[scikit-learn嵌套验证说明](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)。这些数据已被之前模型探索使用，当前仍是探索性比较，不能当成全新外部验证。

| 模型 | 新门控合并371窗RMSE/ns² | TUNING稳定DAC171窗RMSE/ns² |
|---|---:|---:|
| 均值常数 | 8.5516 | 6.8508 |
| 中位数常数 | 8.2099 | 6.8550 |
| 二次曲线 | 8.6471 | 6.9858 |
| 嵌套选择收缩的二次曲线 | 8.2788 | 6.8525 |
| 自由指数＋底噪 | 21.8582 | 6.8655 |
| 固定宽度的饱和曲线 | 11.1745 | 6.8823 |

合并训练的普通二次拟合为R≈44.339+5.817*x−3.340*x²；只在TUNING稳定DAC数据训练却变为R≈48.394−4.351*x+2.546*x²，弯曲方向改变。它们仅为离线候选，不是建议写入控制的参数。

训练拟合并不等同于跨实验预测：饱和曲线将合并数据训练RMSE由均值常数的11.123降到10.670，但跨实验误差仍更大。自由指数的合并拟合最终A=0，但部分留出折在高CN0窄范围内训练后，向v22低CN0区间外推，误差明显增大。完整各折参数与误差均保存，不能只看全量拟合曲线。

## 加上域外回退保护再比较

为区分“曲线本身不合适”和“向未覆盖质量范围外推”的影响，补充一个预先固定的保护规则：验证窗口的平均CN0超出本折训练窗口覆盖的最小～最大值时，退回训练标签中位数；否则用曲线。范围、回退常数和λ都只由该折训练数据得到。这个区间检查只是简单保护，不代表已经完成多维输入域或模型不确定性校准。

| 模型（含域外回退） | 合并371窗RMSE/ns² | TUNING171窗RMSE/ns² |
|---|---:|---:|
| 中位数常数 | 8.2099 | 6.8550 |
| 二次曲线 | 8.1887 | 6.9669 |
| 收缩二次曲线 | 8.1814 | 6.8535 |
| 自由指数＋底噪 | 8.5576 | 6.8690 |
| 饱和曲线 | 8.2098 | 6.8867 |

收缩曲线相对中位数常数误差只低约0.35%。合并数据的各非线性保护方案在留出验证中都有113/371窗退回常数，约30%；TUNING子集只有4窗回退。这说明“有保护的曲线”可以避免明显的域外外推风险，但目前没有值得为其增加控制复杂度的稳定收益证据。

## 判断及下一步

可以研究非线性；不能用相关系数近零把它排除。本次对几种三参数曲线的复核，比单看相关系数更完整，但也不穷尽所有可能的非线性关系。

目前更可能的限制包括：质量指标没有反映主要的PPS/TDC误差、接收机内部处理和实验工况改变、局部真实频率变化进入方差标签、数据相关性。它们是候选解释，尚未唯一归因；不能简单宣称“GNSS质量对授时完全没有影响”。

若继续研究，优先保留一维、低阶、有正值约束和域外回退的曲线。神经网络、随机森林等更灵活模型并非不能用，但371个窗口并不等于371次独立实验，当前也没有证据表明增加自由度会改善控制。

本次建议保持：当前慢环关/开/关继续R80；离线常数候选约46；不要在这三轮中途改成曲线R。若以后选定新模型，应先固定函数和参数再用新记录验证预测，最后才单独验证接管KF后的原始OADEV、平均频差和DAC行为。表观方差标签预测变好，不代表闭环稳定度已经改善。
