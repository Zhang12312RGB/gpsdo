# 四参数R合理性复核与11月2日可选验证

2026年11月1日。当前证据不支持把拟合出的四参数接入控制。数值可求解、预测在已有区间保持正值，与参数关系稳定、跨轮预测有效是不同要求。维持控制R=80 ns²；其含义是保留已测试设置，并非本次标定得到了80或证明80最优。

## 数据与口径

主要检查使用v14、v22、v26的CALIB数据，共33+165+133=331个40秒窗口。v22与v26沿用已经冻结的标签窗口起点，分别从原始REFCHK再计算相位累加、线性去趋势及SSR/(N−2)，最大差仅为CSV四位小数的舍入量。所有窗口保持状态、DAC和分段一致，拒绝样本及质量无效记录不参与。

当前v22原始文件比早先分析快照长，直接用完整文件会得到180个窗口；v26按另一种尾部取整也可得到135个。主结果不吸收这些额外窗口。完整记录扩展另存full_log_sensitivity_results.json，结论方向没有反转。不能把165、167、180或133、135混成同一训练集。

主比较采用统一的残差杠杆权重配对HDOP、SAT及逐样本1/CN0；并用普通窗口均值和1/平均CN0作敏感性检查。二者的系数不应直接混用，原对话给出的四个系数对应后者在v22原标签上的拟合。CALIB局部残差标签含GNSS、TDC、OCXO变化和相关噪声，并非KF纯观测R。

v10/v11缺少相同的现代质量校验，仅作旧数据敏感性检查。v23/v24/v25中满足固定DAC及等待条件的TUNING窗口仅5/11/21个，共37个，单独用于外部诊断，不与冻结数据混合训练。

## 整轮留出结果

每次留出一整轮，只用另两轮训练。不随机打散同轮相邻窗口。表中汇总为各轮RMSE平方按轮等权平均后开方，单位均为ns²。

| 留出轮 | 常数模型 | 线性四参数 | 按原单调假设约束的四参数 |
|---|---:|---:|---:|
| v14 | 7.416 | 7.554 | 7.416 |
| v22 | 16.314 | 16.910 | 16.910 |
| v26 | 9.521 | 10.181 | 9.521 |
| 按轮等权汇总 | 11.716 | 12.202 | 11.994 |

四参数在三次整轮留出中均未超过对应常数模型，汇总误差约高4.1%。这是本批数据的描述性结果，只有三轮，不能当作普遍定理或显著性证明。旧四参数在单独v26上的1.8%改善，不能替代多轮检验；固定40.90常数也不代表常数模型只能取这个数，每一折应只由该折训练数据确定常数。

20秒窗口的按轮等权RMSE：常数16.943，四参数17.399；60秒窗口：常数15.073，四参数15.225。窗口长度改变后仍未看到四参数优势。普通平均特征下40秒结果为11.716对12.198，结论与主比较一致。不同长度的标签本身可能包含不同慢变贡献，不能跨窗口把RMSE高低当作模型改进。

在v23～v25的37个固定DAC TUNING窗口上，用全部现代冻结数据训练，常数RMSE为5.941，四参数为6.181。样本少且受选择条件限制，只作补充诊断，不等同于控制接管实验。

## 参数为什么暂不能直接采用

统一口径下分别拟合各轮，HDOP系数a从v14的−26.84、v22的−11.44变为v26的+6.48；CN0倒数系数c从+2832.15变为−404.99、−98.74。矩阵可满秩，但系数方向缺乏跨轮一致性。SAT系数也会变号。

对v22按120秒及240秒块做2000次移动块重采样，a、b的敏感性区间跨过零；采用较长块时c也跨过零。这只是对相关性和取样变化的敏感性分析，不把块长假设下的区间当严格独立样本置信区间。

上一条给出的原线性系数a=−10.06759、b=+0.35583、c=−405.89891、d=65.44739，与原设计“质量变差时提高R”的单调设想相反。例如固定其他输入，HDOP增加0.5会令R降低约5.03 ns²；CN0由30降至20会令R降低约6.76 ns²。回归偏相关不等于物理因果，不能仅凭符号宣布算法错误，但不宜直接当作在线质量保护律。

## 明天下午是否值得补测

建议先完成视频实拍及最终固件短时功能验收。为了凑四个数，再重复一遍相同五段实验的优先级较低。若仍有约75～90分钟且材料工作不受影响，可增加一次预先固定候选的新一天留出验证：它能检验跨天预测，不能保证确定四个物理系数。

本次另保存tomorrow_frozen_candidates.json：只用现有331个现代冻结窗口拟合一个常数模型和一个四参数模型。它们使用相同训练支持、相同特征定义。已看过v26后合并拟合出的模型属于新的探索候选，v26不再是它们的独立测试集；11月2日整轮才作为新留出。原v22四系数仅保留为辅助诊断，不在看到新数据后替换主候选。

### 最少操作流程

1. 用R80固定、profile0、Tu10、相位项关、慢环MODE0的标定配置。先运行至少15分钟并确认接收与测量连续可靠；若仍有明显热机趋势则延后，不把15分钟视作已经证明热稳定。
2. 只在开始按一次KEY1进入CALIB，记录实际DAC，确认硬冻结。不要强行把DAC设回1886。此后不再按KEY1切回TUNING。
3. 同一小天线按A开阔位置→B较弱但仍正常定位的位置→A回原位置，每段记录20分钟，不拔换天线，不改供电。每次用板上ms标记；可以用KEY2切页辅助留标记。三段共60分钟，理想无缺口时约84个40秒标签。
4. 每段剔除前60秒；窗口不得跨操作、状态、DAC变化、拒绝样本、测量或串口记录缺口。模型保持只读离线计算。接收指标几乎没变时如实记为重复条件，不强称已覆盖四参数。
5. 若有温度计，每5分钟记一次同一位置的温度；没有就注明未测。同步记录天线位置、朝向、天气、供电与BUILD，不用天气代替温度。

### 事先固定的判据

主要指标为原尺度标签RMSE与平均偏差。四参数整体RMSE至少低10%、三段中至少两段不劣、最差段不恶化超过10%，才考虑进入下一步影子验证。这个10%是工程筛选门槛，不是显著性水平；一轮通过也不等于在线接管会改善原始OADEV。输入超出训练范围的窗口另列，不静默删掉，也不把外推结果当确认。

若仍未超过常数，结束本阶段R模型优化；保留固定控制R80、自适应作扩展。若通过，先只记录候选与真实新息，不在同一轮直接切换R控制。每个候选的预测和误差都报告，不在看完新数据后挑某个反变换或窗口。

## 当前建议

不建议直接采用上条四系数；也不建议仅为“得到四个数”安排明天下午实验。现有数据已经支持保持固定R的工程决定。可选补测的价值是新一天留出与复现，同时可取视频过程镜头；优先级低于视频和最终固件功能验收。
