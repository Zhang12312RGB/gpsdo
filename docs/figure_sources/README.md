# 屏幕页面核对资料

extract_screen_layout.py及screen_layout_evidence.json保存对本地TJC.HMI工程活动页面的提取方法和核对结果，用于详图09的控件名称、字段及布局依据。

控制页page0有6项，GNSS页page1有8项。此资料对应作者核对时的屏幕工程，不等于已读回设备当前烧写工程。脚本中的原机器路径属于提取来源，重新提取需提供实际HMI源文件并检查脚本输入，常规编译和数据复现不依赖此脚本。

展示照片见[board/photos](../../board/photos/README.md)，详图说明见[索引](../diagram_index.md)。
