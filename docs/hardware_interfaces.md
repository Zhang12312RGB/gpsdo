# 实物连接与供电确认

2026年11月2日。依据用户确认的旧连接图、当前XDC/源码和新增照片；不改写原图。

开发板AX7010与GNSS/OCXO底板均以5V输入供电。J11的+3.3V脚为扩展口电源定义，与整板5V输入分别记录。按手册图方向，右侧40针接口为J11（PL扩展）；J12为12针PS MIO口，供串口屏连接。

| 链路 | J11脚号 | FPGA管脚 | 方向 |
|---|---:|---|---|
| NMEA | 3 | F17 | 接收机TXD→PL |
| 1PPS | 5 | F20 | 接收机→PL |
| DAC SCK | 7 | G20 | PL→DAC |
| DAC DIN | 9 | H18 | PL→DAC |
| DAC SYNC/CS_N | 11 | L20 | PL→DAC |
| OCXO 20MHz | 16 | K17 | OCXO OUT→PL |
| 地 | 1、37、38 | GND | 公共地 |
| 排针电源 | 39、40 | +3.3V | 排针电源定义 |

J12-9为MIO14/C5 UART0 TX，接屏幕RX；J12-3为MIO15/C8 UART0 RX，接屏幕TX。J12-5/11为GND，6/12为+3.3V。屏幕9600 8N1，PC调试日志115200 8N1。KEY1为MIO50，KEY2为MIO51。默认状态灯为PS LED1 MIO0/E6，低有效；旧图的PL LED功能名称不用于当前默认状态灯说明。

整机当前装配状态的实测外形为245×110×58 mm（长×宽×高），即24.5×11×5.8 cm；高度取整机最高点。AX7010 PCB手册尺寸另为130×90 mm，8层，四个直径3.5 mm安装孔。整机尺寸与单块开发板尺寸分别记录。

GNSS模块近照可识别NEO-M8T-0-11；供电区芯片丝印为LT1963 EQ-3.3。OCXO为外壳标称20.00000MHz；DAC8531为16位器件，当前12位命令左移4位发送。照片用于器件及装配说明，未据照片推算未提供的模拟参数。

## 旧图与当前系统的差异

用户确认旧10MHz连接图的接口定义，除DAC数据/片选换位和LED功能定义外可沿用；系统频率、器件位宽及实现角色按当前代码修正。

| 旧图内容 | 当前采用 |
|---|---|
| OCXO 10MHz | 实物20MHz，周期50ns |
| 12位SPI DAC | DAC8531为16位器件，当前12位命令左移4位、24位串行帧 |
| H18为CS、L20为DIN | H18/J11-9为DIN；L20/J11-11为SYNC/CS_N；G20/J11-7为SCK |
| LED功能名称 | 默认PS LED1/MIO0按频差闪烁，按键MIO50/MIO51；不沿用旧PL LED含义 |
| 电源表述 | AX7010和底板输入均5V，J11排针+3.3V另列 |
| OCXO作为本地测量时钟 | K17为被计数输入，测量域为独立标称100MHz FCLK |

右侧40针排针为J11，屏幕所用12针PS MIO口为J12。完整接线表见hardware_interfaces.md。原长幅PDF保留，不以其旧频率或LED标注替代当前接线说明。报告采用数字链路图与PCB实物，不列未提供的参考电压或阻容数值。
